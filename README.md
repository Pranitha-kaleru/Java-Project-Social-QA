# Community Inquiry – Social Network-Based Q&A Platform

## 📌 Project Overview

Community Inquiry is a web-based Question & Answer platform where users can register, log in, ask questions, answer community questions, and interact based on shared interests. The platform is built using Java, JSP, MySQL, HTML, CSS, and JavaScript.

---

## ✨ Features

- User Registration and Login
- Ask and Answer Questions
- Community-based Discussions
- User Profile Management
- Secure Authentication
- Activity Visualization using JFreeChart

---

## 🛠 Tech Stack

- Java
- JSP
- HTML5
- CSS3
- JavaScript
- MySQL
- JFreeChart

## ⚙ Installation

1. Install Java JDK.
2. Install Apache Tomcat.
3. Install MySQL Server.
4. Import the SQL database.
5. Configure the database connection.
6. Deploy the project on Tomcat.
7. Open the application in your browser.

---

## ▶ How to Run

1. Clone the repository

```bash
git clone https://github.com/Pranitha-kaleru/Java-Project-Social-QA.git
```

2. Import the project into Eclipse.

3. Configure Apache Tomcat.

4. Import the MySQL database.

5. Run the project on the Tomcat server.
